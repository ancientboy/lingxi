# Agent 可视化办公区 - PRD

## 概述
为灵犀云新增「Agent 办公区」页面，让用户能直观地看到每个 Agent 的状态、工作进度和实时活动。

参考产品：腾讯 Marvis 的 Agent 可视化面板

- 后端路由：`/workspace` → 静态文件

## Agent 角色形象设计

### 设计原则
- **纯 CSS/SVG 动画**：不依赖外部图片资源
- **有个性**：每个角色有独特的颜色、发型、装饰
- **有动态**：不同状态有不同的动画（呼吸、工作、庆祝、发呆）
- **可爱但不幼稚**：Q版风格，适合办公场景

### 8 个 Agent 的形象设计

#### 1. 灵犀 ⚡（队长）
- **配色**: 紫色系 (#667eea → #764ba2)
- **特征**: 闪电发饰、披风、自信微笑
- **动作**:
  - 空闲：手托腮思考，偶尔眨眼
  - 工作中：指挥手势，周围闪电流转
  - 派发任务：伸出手指指向

#### 2. 云溪 💻（代码）
- **配色**: 蓝色系 (#4facfe → #00f2fe)
- **特征**: 眼镜、键盘图案T恤、双马尾
- **动作**:
  - 空闲：喝咖啡，悠闲摇晃
  - 工作中：快速敲键盘，代码字符飘起
  - Debug：放大镜，困惑表情

#### 3. 若曦 📊（运营）
- **配色**: 绿色系 (#43e97b → #38f9d7)
- **特征**: 图表发卡、笔记本、马尾辫
- **动作**:
  - 空闲：翻看数据，满意点头
  - 工作中：画图表，数据柱状图升起
  - 发现异常：惊讶表情，感叹号

#### 4. 紫萱 💡（创意）
- **配色**: 橙黄色系 (#fa709a → #fee140)
- **特征**: 灯泡发饰、彩色围巾、短发
- **动作**:
  - 空闲：画画涂鸦，哼歌
  - 工作中：灯泡亮起，灵感迸发
  - 头脑风暴：多个灯泡飘起

#### 5. 梓萱 🎯（产品）
- **配色**: 红色系 (#f5576c → #ff6b6b)
- **特征**: 靶心发卡、西装外套、干练短发
- **动作**:
  - 空闲：整理文件，规划看板
  - 工作中：画原型图，连线
  - 需求评审：严肃表情，叉腰

#### 6. 晓琳 📝（笔记）
- **配色**: 棕色系 (#c79081 → #dab49d)
- **特征**: 书本堆、圆框眼镜、长发
- **动作**:
  - 空闲：看书翻页
  - 工作中：奋笔疾书，文字飘起
  - 整理：文件飞入文件夹

#### 7. 音韵 🎨（多媒体）
- **配色**: 粉紫系 (#a18cd1 → #fbc2eb)
- **特征**: 耳机、画笔、波波头
- **动作**:
  - 空闲：听音乐，节奏摇摆
  - 工作中：画画，色彩飞溅
  - 创作完成：展示作品，自信

#### 8. 智家 🏠（自动化）
- **配色**: 青灰色系 (#89b4c4 → #a8d8ea)
- **特征**: 齿轮发卡、工具腰带、丸子头
- **动作**:
  - 空闲：调试小装置
  - 工作中：齿轮转动，火花飞溅
  - 完成任务：举手庆祝

### 动画状态定义

| 状态 | 图标 | 角色动画 | 卡片效果 |
|------|------|---------|---------|
| 空闲 idle | 🟢 | 呼吸 + 小动作 | 轻微发光 |
| 工作中 working | 🔵 | 专注动作 + 工具特效 | 边框流光 |
| 排队 queued | 🟡 | 看表/等待 | 脉冲闪烁 |
| 错误 error | 🔴 | 抓头/叹气 | 红色警告边框 |
| 离线 offline | ⚪ | 静止/灰度 | 灰色蒙层 |

## 技术方案

### 前端
- **文件**: `frontend/agent-workspace.html`
- **角色渲染**: 纯 CSS + SVG 动画（无需图片）
- **实时更新**: WebSocket 推送 + 5s 轮询降级
- **样式**: 复用现有 `chat.css` 的暗色主题变量

### 后端
- **文件**: `backend/routes/agent-workspace.js`
- **数据来源**:
  1. OpenClaw Gateway API（`/api/sessions`）获取 Agent session 状态
  2. WebSocket 事件流（`agent-status`, `task-progress`）
- **API 端点**:
  - `GET /api/agent-workspace/status` — 所有 Agent 状态
  - `GET /api/agent-workspace/tasks` — 当前任务列表
  - `GET /api/agent-workspace/logs` — 最近活动日志
  - `WebSocket` 实时推送状态变化

## 实现步骤

### Phase 1 - 基础框架 (优先)
1. 创建 `agent-workspace.html` 页面
2. 8 个 Agent 的 SVG 角色卡片（含基础动画）
3. 状态显示（颜色编码）
4. 侧边栏入口

### Phase 2 - 后端对接
5. 创建 `agent-workspace.js` 路由
6. 对接 OpenClaw sessions API
7. WebSocket 实时推送

### Phase 3 - 动画增强
8. 每个角色的状态动画（空闲/工作/错误）
9. 任务进度条动画
10. 实时日志滚动

### Phase 4 - 打磨
11. 响应式适配
12. 性能优化（动画帧率）
13. 主题适配（暗色/亮色）
